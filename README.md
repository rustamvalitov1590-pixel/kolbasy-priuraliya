# Сайт «Колбасы Приуралья»

Статический сайт без сборки и зависимостей: HTML + CSS + JavaScript.
Можно разместить на любом хостинге (Netlify, Vercel, GitHub Pages, Cloudflare Pages, обычный shared-хостинг).

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: первый экран, категории, хиты, халал и бренды, производство, магазин, опт |
| `catalog.html` | Каталог: поиск, фильтр по категориям, сортировка, карточка товара, корзина |
| `about.html` | О компании, производство, халал, торговые марки |
| `contacts.html` | Магазин и карта, быстрая связь, заявка для оптовиков, реквизиты |

## Где что редактировать

- **Товары, цены, категории, контакты, режим работы** — `js/data.js`.
  - `config.whatsapp` — номер, на который приходят заказы из корзины.
  - `config.hours` — режим работы (по нему считается «Открыто / Закрыто»).
  - `products[]` — ассортимент. `unit: 'кг'` — весовой товар (шаг 0,5 кг), `'шт'` — штучный.
  - `tags: ['hit']` — попадёт в блок «Чаще всего берут» на главной, `['new']` — метка «Новинка».
- **Стили** — `css/styles.css` (цвета и размеры — в переменных `:root` в начале файла).
- **Фото** — `assets/img/`. Квадратные фото товаров 800×800, широкие 1600×914.

> ⚠️ Перед запуском сверьте с заказчиком: цены и часть позиций в `js/data.js` ориентировочные.
> Фото сейчас иллюстративные — замените на реальные фото продукции.
> В шапке, подвале и на странице контактов телефоны и адрес продублированы в HTML (для SEO) — при смене контактов поправьте их во всех четырёх HTML-файлах.

## Как работает заказ

Корзина хранится в браузере (localStorage). При оформлении собирается сообщение
со списком товаров, именем, телефоном и способом получения и открывается WhatsApp
с готовым текстом на номер `config.whatsapp`. Сервер и база данных не нужны.

## Адаптивность

- до 1023 px — режим «приложения»: компактная шапка, нижняя панель вкладок,
  карусели, шторки снизу со свайпом для закрытия, учёт safe-area у iPhone;
- от 1024 px — классический сайт: верхняя панель, меню, сетки по 4 карточки,
  корзина — боковая панель, карточка товара — модальное окно.
- Можно «установить» на телефон как приложение (manifest + иконки).

## Локальный просмотр

Открыть `index.html` двойным кликом либо запустить любой статический сервер в папке, например:

```
npx serve .
```
